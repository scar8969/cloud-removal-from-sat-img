About This Project

Problem

Clouds frequently obscure satellite imagery, preventing accurate analysis for agriculture monitoring, disaster response, and urban planning.

Solution

A U-Net denoising autoencoder trained on synthetic cloudy images. No ground truth needed — unlimited training data via synthetic cloud generation.

Innovation

  • Synthetic cloud generation (Gaussian blobs)
  • Lightweight U-Net (118K params)
  • CPU-only training (~1 minute)
  • Fast inference (< 50ms)

Tech Stack

Python PyTorch OpenCV NumPy Flask HTML/CSS/JS
